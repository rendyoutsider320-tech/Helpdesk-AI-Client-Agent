# Helpdesk AI Frontend

Next.js + Tailwind CSS + Zustand

Frontend application for the Helpdesk AI system.

## Structure

```
web/
├── package.json
├── next.config.js
├── tailwind.config.ts
├── tsconfig.json
└── src/
    ├── app/
    ├── components/
    ├── lib/
    ├── store/
    └── hooks/
```

## Development

```bash
npm install
npm run dev
```

Frontend accessible at http://localhost:3000
